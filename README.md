# SQL Sales Analysis

Supermarket Sales Analysis using SQL | JOIN, GROUP BY, Window Functions

## 📊 Project Overview
Analyzed Supermarket Sales Dataset (1000 rows) from Kaggle using SQL to find sales patterns by Branch, Product Line, Payment Method and Customer Type.

## 🛠️ Tools Used
- SQL (MySQL)
- GitHub

## 📂 Files
- analysis.sql - Contains all 7 SQL queries

## 🔍 Key Queries
1. Total Sales by Branch
2. Total Sales by Product Line
3. Sales by Payment Method
4. Sales by Customer Type & Gender
5. Top 5 Best Selling Product Lines
6. Monthly Sales Trend with Window Function
7. Ranking Product Lines using CTE & RANK()

## 💡 Key Insights
- Yangon branch has the highest sales
- Food and Beverages is the top selling product line
- E-wallet is the most used payment method
- Member customers spend more than Normal customers

## 📌 How to Run
1. Import `supermarket_sales.csv` into MySQL
2. Run queries from `analysis.sql`
